# UI спецификация

## Расположение

- **Слева** — панель документов (вкладки, список файлов)
- **Справа** — область редактирования блокнота

## Отображение (реализовано)

- **Monaco Editor** — единое поле ввода (как textarea в Calque), язык `calq`
- **Результаты inline** — отображаются сразу после кода в каждой строке (overlay с pointer-events: none поверх редактора)
- Строки разделяются символом `\n`

### Пример

```
a = 5             5
b = a * 2         10
b + 10            20
```

### Подсветка синтаксиса (Monaco Monarch)

- Переменные — цвет chart-2
- Числа — цвет chart-1
- Операторы — приглушённый foreground
- Функции (sin, cos, sqrt и т.д.) — цвет chart-3
- Комментарии (#) — muted, курсив
- Результат вычисления — chart-2, жирный
- Поддержка кириллицы в идентификаторах

### Стилизация строк

- Чередование фона: каждая вторая строка — bg-muted/30
- Подсветка текущей строки (где курсор) — bg-accent/20, ring

### Ошибки

- Справа вместо результата — текст ошибки
- Подсветка строки с ошибкой (красный цвет)

---

## Редактирование

Пользователь может:

- редактировать текст в Monaco Editor
- добавлять строку (Enter) — нативное поведение
- удалять строку (Backspace на пустой строке) — нативное поведение
- использовать автодополнение (Ctrl+Space) — переменные и функции с подсказками

После изменения выполняется пересчёт.

---

## Клавиатура (обязательный функционал)

| Клавиша | Действие |
|---------|----------|
| **Enter** | Новая строка ниже текущей (нативно) |
| **Ctrl+S** (Cmd+S на Mac) | Сохранить документ |
| **Backspace** на пустой строке | Удалить строку (нативно) |

### Не обрабатываются в MVP

- Tab
- Ctrl+N
- Ctrl+W

---

## Тема

- Светлая/тёмная по prefers-color-scheme
- Выбор сохраняется в localStorage
- Переключатель в UI (theme-toggle)

---

## Документы (панель слева)

- Список документов с названиями
- Индикатор несохранённых изменений (точка/звёздочка)
- Кнопка создания документа
- Кнопка удаления (отключена для пустого документа — 0 строк)
- Переименование по клику/двойному клику

## Локализация

- react-i18next
- Переводы колоцированы со слайсами (внутри каждой фичи/виджета/страницы/сущности)
- Инжект: `injectTranslation(TRANS_NS, translations)` в index.ts слайса
- Использование: `useTranslation(TRANS_NS)` в компонентах
- Язык по умолчанию: русский
- Подробнее: [docs/coding-standards.md](../docs/coding-standards.md#локализация-react-i18next)
