# Целевое решение — обзор

Верхнеуровневое описание системы Calqnotes.

---

## Что это

Веб-приложение: интерактивный вычислительный блокнот. Пользователь работает с документами, каждый документ — список строк. Строка = выражение + результат. При изменении выражений результаты пересчитываются автоматически.

---

---

## Поток данных

1. **Пользователь редактирует строку** → событие LINE_UPDATED → вызов Evaluation Engine → обновление результатов → перерисовка UI.

2. **Пользователь нажимает Enter** → LINE_ADDED → новая строка вставляется → пересчёт → перерисовка.

3. **Пользователь нажимает Backspace на пустой строке** → LINE_REMOVED → строка удаляется → пересчёт → перерисовка.

4. **Пользователь нажимает Ctrl+S** → сохранение в IndexedDB → сброс isDirty.

5. **Пользователь переключает документ** → DOCUMENT_SWITCHED → загрузка строк из state (или из IndexedDB при первом открытии).

6. **Пользователь создаёт/удаляет/переименовывает документ** → обновление списка документов, при удалении — проверка на пустой документ и предупреждение при несохранённых изменениях.

---

## Слои

| Слой | Ответственность |
|------|-----------------|
| **UI** | React-компоненты, отображение, ввод, клавиатура |
| **State** | Документы, строки, активный документ, isDirty |
| **Evaluation** | Вычисление выражений через math.js, scope, кэш |
| **Storage** | IndexedDB: сохранение, загрузка, CRUD документов |

---

## Ключевые решения

- **Один документ = один блокнот** — raw text, строки через `\n`.
- **Monaco Editor** — единое поле ввода (как textarea в Calque), подсветка, автодополнение, колонка результатов справа.
- **Zustand** — стейт-менеджер.
- **Полный пересчёт** при изменении (MVP) — без графа зависимостей.
- **Сохранение по кнопке** — автосохранение в roadmap.
- **Локализация с первого дня** — строки в файлах, не в коде.
- **Движок без UI** — `evaluateNotebook(lines)` не зависит от React.
