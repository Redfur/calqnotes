# Исследование Calque

Анализ [Calque](https://github.com/grimalschi/calque) для понимания внутренней работы и определения, что можно использовать, а что переписать.

---

## Архитектура Calque

### UI модель

- **Один textarea** — весь ввод (все строки в одном поле)
- **Один div** — вывод результатов (рендерится как HTML)
- Синхронизация скролла: `outputEl.scrollTop = inputEl.scrollTop`
- Строки разделяются символом `\n`

### Хранение

- **localStorage** — ключ `"input"`, значение — сырой текст
- Загрузка при `window.onload`
- Сохранение при каждом `oninput` (с debounce через `Date.now()`)

### Зависимости

- **math.js** v5.9.0 — бандл в репозитории (math.js, math.min.js)
- Обычный math.js от josdejong, без модификаций

## Вычисление (recalc)

### Алгоритм

1. Разбить `raw` по `\n` на строки
2. Для каждой строки создать объект `line` с полями: `index`, `code`, `positionStart`, `positionEnd`, `result`, `error`, `indent`, `summing`, `closed`, `children`
3. **Последовательно** обработать строки:
   - Определить indent (пробелы в начале, по 2 пробела = 1 уровень)
   - Если строка заканчивается на `:` (summing block) — инициализировать `summing`, `result = 0`
   - Иначе: `math.parse(code)` → `compile()` → `eval(scope)`
   - Scope — объект, накапливается по ходу: `scope.last`, переменные из assignment, переменные из summing blocks

### Scope

```javascript
var scope = { last: null };

// При успешном вычислении:
scope.last = line.result;

// При assignment (a = 5) — math.js сам пишет в scope при eval

// Summing blocks — вручную:
scope[line2.summing] = line2.result;
```

### Кэширование

```javascript
calque.cache = {};

// Для каждой строки:
var cached = calque.cache[line.code];
if (!cached) {
  cached.parsed = math.parse(line.code);
  cached.compiled = cached.parsed.compile();
}
line.result = line.compiled.eval(scope);
```

Кэш по **полному тексту строки** (`line.code`). При изменении одной строки — пересчёт **всех** строк сверху вниз. Кэш ускоряет только повторный parse/compile для неизменённых строк.

### Граф зависимостей

**Отсутствует.** Calque каждый раз пересчитывает все строки заново. Нет инкрементального пересчёта.

## Специальные возможности Calque

### 1. Summing blocks (вложенные списки)

```
animals:
  cats = 2
  dogs = 3
```

- Строка с `:` в конце — заголовок блока
- Indent (2 пробела = 1 уровень) определяет вложенность
- Дочерние строки суммируются в `line.result` через `math.add`
- В scope попадает `scope["animals"] = line.result`

**MVP:** не используем (TODO)

### 2. Переменная `last`

- `scope.last` обновляется после каждой успешной строки
- math.js поддерживает `last` как обычную переменную

**MVP:** не используем (TODO)

### 3. Единицы измерения

- `2 inch to cm` — встроено в math.js
- Работает из коробки при использовании math.js

**MVP:** не используем (TODO)

### 4. Пользовательские функции

- `pow2(x) = x ^ 2` — math.js поддерживает через `FunctionAssignmentNode`
- При eval создаётся функция в scope

**MVP:** не используем (TODO)

### 5. Имена переменных с пробелами

- `postal code = 1122` — math.js поддерживает

**MVP:** можно оставить или ограничить `[a-zA-Z_][a-zA-Z0-9_]*` по спецификации

## Клавиатура Calque

| Клавиша | Действие |
|---------|----------|
| Enter | Новая строка + отступ (если summing) |
| Ctrl+D / Ctrl+В | Дублировать строку или выделение |
| ArrowUp/Down | Изменить число ±1 (или ±10 с Shift) |

| Shift+Tab | Убрать отступ |

## Repaint (отображение)

Calque рендерит **только output** — div с результатами. Input — нативный textarea.

Для каждой строки определяется `type`:
- `result` — показать результат
- `error` — показать ошибку
- `empty` — пусто (для assignment, constant, function, или при ошибке в выделенной строке)

Формат: `prefix + data`, где prefix = `= ` или `// `, data = результат или текст ошибки.

## Что можно использовать

| Компонент | Использование |
|-----------|----------------|
| **math.js** | npm-пакет `mathjs`. API: `math.parse()`, `node.compile()`, `compiled.eval(scope)`. Полная совместимость. |
| **Scope-объект** | Тот же подход: объект `{ last: null }`, накопление переменных при eval. |
| **Кэш parse/compile** | Идея переносится: кэшировать по `line.code`. При полном пересчёте ускоряет. |
| **Последовательный пересчёт** | Алгоритм «сверху вниз» — базовый. Для MVP достаточно. |
| **Обработка ошибок** | try/catch, `e.toString()` в `line.error`. Аналогично. |

## Рекомендации для реализации

1. **Движок вычислений** — отдельный модуль (например, `evaluateNotebook(lines)`), без привязки к React. Внутри: math.js, scope, кэш.
2. **math.js** — использовать `math.parse()` + `compile()` + `eval(scope)`. Для assignment math.js сам обновляет scope.
3. **MVP без графа зависимостей** — полный пересчёт при любом изменении. Граф — оптимизация для больших документов.
4. **Структура строки** — массив объектов `{ id, input }`, а не один текст. Удобнее для React и для будущего графа.
5. **Кэш** — по `input` строки. При изменении одной строки пересчёт всех, но parse/compile только для изменённых.
