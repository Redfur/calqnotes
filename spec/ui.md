# UI спецификация

## Расположение

- **Слева** — панель документов (вкладки, список файлов)
- **Справа** — область редактирования блокнота

## Отображение строки

Каждая строка отображается как:

```
[input field]     [result]
```

### Пример

```
a = 5             5
b = a * 2         10
b + 10            20
```

### Ошибки

- Справа вместо результата — текст ошибки
- Подсветка строки с ошибкой (например, красная рамка или фон)

---

## Редактирование

Пользователь может:

- редактировать input строки
- добавлять строку ниже (Enter)
- удалять строку (Backspace на пустой строке)

После изменения строки выполняется пересчёт.

---

## Клавиатура (обязательный функционал)

| Клавиша | Действие |
|---------|----------|
| **Enter** | Новая строка ниже текущей |
| **Ctrl+S** (Cmd+S на Mac) | Сохранить документ |
| **Backspace** на пустой строке | Удалить строку |

### Не обрабатываются в MVP

- Tab
- Ctrl+N
- Ctrl+W

---

## Документы (панель слева)

- Список документов с названиями
- Индикатор несохранённых изменений (точка/звёздочка)
- Кнопка создания документа
- Кнопка удаления (отключена для пустого документа — 0 строк)
- Переименование по клику/двойному клику

---

## Доступность

Опора на shadcn (Radix UI) и встроенные атрибуты доступности.

---

## Локализация

- Разработка с учётом файлов локализации с самого начала
- Язык по умолчанию: русский
- Структура должна позволять безболезненно добавить другие языки
