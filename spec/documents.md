# Документы и хранение

## Общие правила

- Один документ = один блокнот
- Вкладки слева = список документов в сессии
- Документ содержит упорядоченный список строк

## Хранение

- **IndexedDB** — хранение документов в браузере
- Сохранение по кнопке «Сохранить»
- [ ] Автосохранение каждые X секунд/минут (будущее)

## Именование

- По умолчанию: «Без названия 1»
- Если «Без названия 1» уже есть → «Без названия 2», «Без названия 3» и т.д.
- Пользователь может переименовать
- Проверка на уникальность названия при переименовании

## Операции с документами

| Действие | Поведение |
|----------|-----------|
| Создать | Кнопка создания нового документа |
| Удалить | Кнопка удаления документа |
| Переименовать | Редактирование названия с проверкой уникальности |

### Удаление пустого документа

- Пустой документ = 0 строк
- При попытке удалить пустой документ: **игнорировать** и показать его (или отключить кнопку удаления)
- Остальные документы можно удалять

## Первый запуск

При отсутствии документов — сразу создать «Без названия 1».

## Несохранённые изменения

- **Индикатор** — точка или звёздочка у названия вкладки при наличии несохранённых изменений
- **Переключение на другой документ** — переключать без предупреждения
- **Закрытие вкладки** с несохранёнными изменениями — **предупреждать**
