# Нефункциональные требования

## Производительность

- Пересчёт должен выполняться **менее чем за 16ms** для документов до 200 строк

## Масштабируемость

Система должна поддерживать:

- минимум **500 строк**
- минимум **100 переменных**

## Мобильные устройства

- **Адаптивность** — корректное отображение на мобильных
- **Мобильная клавиатура** — поддержка обычной мобильной клавиатуры для ввода

## Доступность

Опора на shadcn (Radix UI) и его атрибуты для доступности.

## Локализация

- react-i18next, колоцированные переводы (внутри слайсов)
- Русский язык по умолчанию
- Возможность добавить другие языки без переработки
