# Домен: выражения, вычисления, переменные

## Библиотека вычислений

**math.js** — используется для парсинга и вычисления выражений.

## MVP: типы выражений

### Expression

Обычное математическое выражение.

```
2 + 2
sin(0.5)
10 * 5
```

### Assignment

Присваивание переменной.

```
a = 10
b = a * 2
```

### Result reference

Использование переменной в выражении.

```
a + 5
```

### Комментарии

Строка, начинающаяся с `#`, не вычисляется. Внутри строки всё после `#` игнорируется.

```
# это комментарий
a = 5   # присваивание с комментарием
```

- [x] Переменная `last` — результат предыдущей строки доступен как `last` в scope (обновляется после каждой успешной строки)

## Правила вычисления

Все строки вычисляются **сверху вниз**.

### Алгоритм

1. Создаётся пустой scope
2. Строки обходятся по порядку
3. Каждая строка вычисляется
4. Если строка объявляет переменную — она добавляется в scope

### Псевдокод

```
scope = {}

for line in lines:
  result = evaluate(line.input, scope)

  if assignment:
    scope[var] = result

  if result is valid:
    scope.last = result
```

## Правила переменных

Переменная определяется строкой вида:

```
name = expression
```

### Имя переменной

- Начинается с буквы (латиница, кириллица, греческий)
- Может содержать цифры и underscore
- Регулярное выражение: `[a-zA-Z_\u0400-\u04FF][a-zA-Z0-9_\u0400-\u04FF]*`

---

## Зависимости

Каждая строка содержит список переменных, которые используются в выражении.

### Пример

```
a = 5
b = a * 2
c = b + a
```

**Граф зависимостей:**

```
a → b
a → c
b → c
```

---

## Правила пересчёта

При изменении строки:

1. Определяется изменённая переменная
2. Находятся строки, которые от неё зависят
3. Пересчитываются только они

### Алгоритм

```
changed = line
affected = dependencyGraph.getDependents(changed)
recalculate(changed + affected)
```

## Ошибки вычисления

| Тип | Описание |
|-----|----------|
| **syntax error** | Синтаксическая ошибка в выражении |
| **undefined variable** | Использование необъявленной переменной |
| **math error** | Математическая ошибка (деление на ноль и т.п.) |

### Отображение ошибок

- Справа вместо результата — текст ошибки
- Подсветка строки с ошибкой

### Пример

```
a = 5
b = c + 2
```

**Ошибка:** `undefined variable: c`
