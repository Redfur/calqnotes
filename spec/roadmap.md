# Расширяемость и будущие возможности

## Расширяемость

Движок должен поддерживать подключение:

- кастомных функций
- единиц измерения
- дополнительных типов данных

### Интерфейс

```ts
registerFunction(name: string, fn: (...args: number[]) => number)
```

---

## Реализовано

- [x] Подсветка синтаксиса (Monaco Editor + Monarch)
- [x] Автодополнение переменных и функций (Monaco CompletionItemProvider)
- [x] Переменная `last` (результат предыдущей строки, scope.last)
- [x] Поддержка кириллицы в идентификаторах (патч parse.isValidLatinOrGreek)
- [x] Кэширование parse/compile (parseCache в evaluate.ts)
- [x] Тема светлая/тёмная (prefers-color-scheme + localStorage)
