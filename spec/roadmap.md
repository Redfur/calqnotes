# Расширяемость и будущие возможности

## Расширяемость

Движок должен поддерживать подключение:

- кастомных функций
- единиц измерения
- дополнительных типов данных

### Интерфейс

```ts
registerFunction(name: string, fn: (...args: number[]) => number)
```
