# Домен: выражения, вычисления, переменные

## Библиотека вычислений

**math.js** — используется для парсинга и вычисления выражений.

## MVP: типы выражений

### Expression

Обычное математическое выражение.

```
2 + 2
sin(0.5)
10 * 5
```

### Assignment

Присваивание переменной.

```
a = 10
b = a * 2
```

### Result reference

Использование переменной в выражении.

```
a + 5
```

### Комментарии

Строка, начинающаяся с `#`, не вычисляется. Внутри строки всё после `#` игнорируется.

```
# это комментарий
a = 5   # присваивание с комментарием
```

### Проценты

Как в обычном калькуляторе (поддерживает math.js), плюс `of`:

```
1250 - 15%      # 1062,5
20% of 500      # 100
```

### Единицы

Единицы math.js и перевод через `to` / `in`. Результат хранит единицу и показывает её в плашке.

```
2 inch to cm            # 5,08 cm
5 km / 25 min to km/h   # 12 km/h
```

Единица, имя которой занято функцией math.js (`min`), после числа и после `to` читается как единица.

## Правила вычисления

Все строки вычисляются **сверху вниз**.

### Алгоритм

1. Создаётся пустой scope
2. Строки обходятся по порядку
3. Каждая строка вычисляется
4. Если строка объявляет переменную — она добавляется в scope

### Псевдокод

```
scope = {}

for line in lines:
  result = evaluate(line.input, scope)

  if assignment:
    scope[var] = result

  if result is valid:
    scope.last = result
```

## Правила переменных

Переменная определяется строкой вида:

```
name = expression
```

### Имя переменной

- Одно или несколько слов через пробел: `на руки = зарплата - налог`.
- Слово начинается с буквы (латиница, кириллица) или `_`, дальше буквы, цифры, `_`.
- Слова `of`, `to`, `in`, `mod`, `and`, `or`, `not`, `xor` в имени не допускаются.
- Многословные имена перед вычислением заменяются служебными идентификаторами, в ошибках и подсказках показываются как написаны.
- Строка, которая только задаёт число (`цена = 1500`), результата не показывает.

---

## Зависимости

Каждая строка содержит список переменных, которые используются в выражении.

### Пример

```
a = 5
b = a * 2
c = b + a
```

**Граф зависимостей:**

```
a → b
a → c
b → c
```

## Правила пересчёта

Сейчас при любом изменении пересчитывается вся заметка (с кэшем разбора выражений). Ниже — целевой алгоритм.

При изменении строки:

1. Определяется изменённая переменная
2. Находятся строки, которые от неё зависят
3. Пересчитываются только они

### Алгоритм

```
changed = line
affected = dependencyGraph.getDependents(changed)
recalculate(changed + affected)
```

## Ошибки вычисления

| Код | Текст |
|-----|-------|
| `undefinedVariable` | Нет переменной «…» |
| `unknownUnit` | Нет единицы «…» |
| `missingParen` | Не хватает «)» |
| `incomplete` | Выражение не закончено |
| `unitMismatch` | Единицы несовместимы |
| `divisionByZero` | Деление на ноль |
| `notANumber` | Результат — не число |
| `unsupported` | Такой результат пока не поддерживается |
| `invalid` | Не получается посчитать |

Для неизвестного имени движок ищет ближайшее известное (до 1 опечатки на 4 символа): переменные, в том числе из нескольких слов, `last` и функции, а после числа или `to` — единицы.

### Отображение ошибок

- Плашка с иконкой и текстом после выражения, неизвестное имя подчёркнуто.
- Кнопка «Возможно, …?» заменяет опечатку.
- Ошибка в одной строке не мешает считать следующие.

### Пример

```
на руки = 160950
на рукки * 12     # Нет переменной «на рукки» · Возможно, на руки?
```
