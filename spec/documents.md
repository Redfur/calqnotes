# Документы и хранение

## Общие правила

- Одна заметка = один блокнот: упорядоченные строки, хранятся как текст через `\n`.
- Список заметок отсортирован по дате изменения, сначала свежие.

## Хранение

- **IndexedDB** `calqnotes`, хранилище `documents`, версия схемы **3**.
- Запись заметки: `id`, `name`, `lines` (`{ id, input }[]`), `sortOrder`, `createdAt`, `updatedAt`, `precision` (`"auto"` | число знаков | `null` — как во всех заметках), `example`.
- Миграция v2 → v3: `createdAt` из `sortOrder`, `updatedAt` = время обновления, `precision = null`. Старые заметки не теряются.
- Если другая вкладка открывает новую версию схемы, текущая отпускает базу (`blocking`).
- **localStorage:**
  - `calqnotes-last-active-doc` — последняя открытая заметка;
  - `calqnotes-settings` — настройки (формат чисел, тема, шрифт, редактор);
  - `calqnotes-theme` — тема старой версии, переносится в настройки при первом запуске.

## Сохранение

- **Автосохранение** через 1 с после последнего изменения; Ctrl S — сразу.
- При выключенном автосохранении — только Ctrl S, статус «Не сохранено».
- Ошибка записи — статус «Не удалось сохранить» и «Повторить».
- Закрытие вкладки, пока изменения не записаны, — предупреждение (`beforeunload`).

## Название

- Новая заметка без названия: заголовок берётся из первой непустой строки (без `#`, до 40 символов), иначе «Без названия».
- Переименование — в шапке, в палитре (F2) или в меню заметки. Уникальность не требуется.
- Копия — «<название> (копия)».

## Операции

| Действие | Поведение |
|----------|-----------|
| Создать | Кнопка «+» в шапке, «Новая заметка» в палитре и списке, «Создать заметку «…»» из поиска |
| Дублировать | Копия текста и точности, открывается сразу |
| Удалить | Сразу удаляется из базы; тост «Отменить» 6 с возвращает её. Если удалена последняя заметка, создаётся пустая |
| Переименовать | См. «Название» |

## Первый запуск

Базы нет или она пустая — создаётся заметка-пример «Как пользоваться» (`example: true`) с баннером. Её можно удалить и создать заново из шпаргалки.

## Экспорт

«Скачать .txt» и «Скачать все заметки» пока неактивны («Скоро»). Есть «Скопировать с результатами»: строка с расчётом копируется как `выражение = результат`.
