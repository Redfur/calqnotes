# Термины

| Термин | Определение |
|--------|-------------|
| **Notebook** | Документ, содержащий упорядоченный список строк |
| **Document** | Файл блокнота с уникальным именем, хранится в IndexedDB |
| **Line** | Отдельная строка ввода выражения |
| **Expression** | Математическое выражение |
| **Assignment** | Выражение, присваивающее значение переменной |
| **Scope** | Таблица переменных, доступных для вычислений |
| **Dependency** | Связь строки с переменной из другой строки |
| **Evaluation Engine** | Компонент, выполняющий вычисления (на базе math.js) |
| **Пустой документ** | Документ с 0 строк |
