# Функциональные требования

## MVP (первая версия)

### Возможности пользователя

- вводить математические выражения
- использовать переменные (присваивание и использование)
- переиспользовать результаты предыдущих строк
- редактировать строки
- добавлять новые строки
- удалять строки
- видеть результат вычисления
- создавать, удалять, переименовывать документы
- переключаться между документами (вкладки слева)
- сохранять документы (автоматически или по Ctrl S)

### Поведение системы

- Автоматический пересчёт результатов после изменения входных данных
- Хранение в IndexedDB
- При первом запуске — создание документа «Без названия 1»
- Предупреждение при закрытии вкладки с несохранёнными изменениями (beforeunload)
- Сортировка заметок по дате изменения

## Реализовано сверх MVP

- Переменная `last` (результат предыдущей строки)
- Подсветка синтаксиса (CodeMirror 6)
- Автодополнение переменных и функций
- Поддержка кириллицы в переменных, имена из нескольких слов
- Кэширование parse/compile
- Тема: как в системе / светлая / тёмная
- Единицы измерения (`2 inch to cm`) и проценты (`20% of 500`)
- Формат результата: округление, разделители, экспонента; точность для отдельной заметки
- Копирование результата кликом, «Скопировать с результатами»
- Ошибки на русском с подсказкой ближайшего имени
- Автосохранение, дублирование, удаление с отменой, поиск по заметкам
- Шпаргалка, заметка-пример при первом запуске
- Мобильная версия
