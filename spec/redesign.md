# Переезд на новый дизайн

> **Статус:** этапы 0–7 выполнены в ветке переезда, кроме пунктов, отмеченных ниже. Описание нового UI — [ui.md](./ui.md), архитектура — [architecture.md](./architecture.md).

План перехода с текущего UI на дизайн из [макетов](https://claude.ai/artifact/FQ9E2gmpqFpLNG2vSEt6r2) (18 артбордов: главный экран, заметки, настройки, шпаргалка, первый запуск, телефон, планшет, состояния строк, токены).

## Коротко

- **Старый UI не архивируем, а заменяем.** Перед началом ставим git-тег `legacy-ui`. Папку `legacy/` не заводим: мёртвый код в дереве мешает FSD-импортам и поиску. Ядро (движок, хранилище, стор, i18n, тема) остаётся и дорабатывается. Слой UI (`widgets/`, `pages/`, `features/`) пишется заново, старые слайсы удаляются в том же PR, где появляется замена.
- **Редактор меняем с Monaco на CodeMirror 6.** Главное в макетах — кликабельная плашка результата сразу после текста строки, которая при нехватке места переносится вниз, плюс нормальная работа на телефоне. В Monaco это нестандартные content widgets, которые не участвуют в переносе строк, а мобильные браузеры Monaco официально не поддерживает.
- **Текущую версию не дорабатываем.** Переезд идёт в одной ветке и вливается в `main` одним PR, когда новый UI готов полностью: каждый push в `main` деплоится на GitHub Pages, и полупереехавшее приложение увидели бы пользователи. Этапы ниже — отдельные коммиты в этой ветке.
- **Экспорт в .txt** пока не делаем: в меню заметки пункт «Скачать .txt» с пометкой «Скоро». Формат экспорта проработаем отдельно.
- **Переводы.** Все тексты нового UI — в файлах `translations.ts` слайсов, сейчас только `ru`. Английский язык и пункт «Язык» в настройках добавим отдельно; до тех пор пункта в настройках нет.

## Ядро: что нужно движку

Проверено на текущем math.js 15: часть выражений из макетов уже работает, часть нет.

| Выражение из макетов | Сейчас | Что сделать |
| --- | --- | --- |
| `1250 * 12 - 15%`, `1250 - 15%` | Работает | Ничего |
| `2 inch to cm`, `72 kg to lb`, `sin(30 deg)`, `17 mod 5` | math.js считает, но `Number(Unit)` теряет единицу | Результат — структура `{ value, unit? }`, `scope` не только числа |
| `20% of 500` | `Undefined symbol of` | Предобработка `X% of Y` → `Y * X / 100` |
| `5 km / 25 min to km/h`, `2 h + 30 min` | `min` и `h` — функция и константа | Предобработка: число + единица имеет приоритет над функцией |
| `на руки = зарплата - налог` | Пробелы в именах не поддерживаются | Предобработка: известные многословные имена заменяются служебными идентификаторами, обратно — при выводе ошибок и подсказок |
| `5 / 0` | `Infinity` | Ошибка «Деление на ноль» |
| `зарплата = 185000` | Результат показывается | Флаг «строка только задаёт число» — плашку не показываем |
| Ошибки | Английский текст math.js | Коды ошибок → русские тексты; для неизвестного имени — ближайшая переменная или единица (расстояние Левенштейна) |
| Подсветка зависимостей | Нет данных | Движок возвращает для строки определяемое имя и список использованных имён |
| `0.1 + 0.2` | `0.30000000000000004` | Решает форматтер, движок не трогаем |

**Форматтер** — чистая функция `formatResult(result, settings) → { text, rounded, exact }` в `entities/line/lib`. Режимы: авто (до 2 знаков, у чисел меньше 1 — 4 значащие цифры), фиксированное число знаков (0–10), значащие цифры. Плюс разделители разрядов и дробной части, нули в конце, порог экспоненциальной записи, знак минус `−`. Округление влияет только на вывод: в расчётах и в `last` всегда точное значение.

**Тесты.** Сейчас их нет. На этапе 0 добавляем Vitest и покрываем движок и форматтер таблицей «выражение → результат» из макетов (`States`, `Help`, `Welcome`). Это защитит от регрессий при переписывании UI.

## Данные

- **IndexedDB v3:** у заметки появляются `updatedAt` (даты в списке, сортировка) и `settings` (точность для отдельной заметки). При обновлении `updatedAt` заполняется текущим временем, существующие заметки не теряются.
- **Настройки приложения** — отдельный Zustand-стор с `persist` в `localStorage`: формат чисел, тема, язык, шрифт, размер текста, переключатели редактора.
- **Автосохранение:** debounce ~1 с после ввода, статус в шапке. Ctrl+S остаётся как «сохранить сейчас», `beforeunload` — только пока сохранение не завершилось.
- **Удаление с отменой:** заметка сразу скрывается из списка, а запись в базе удаляется через 6 с, если не нажали «Отменить».

## Риски

- **Многословные имена переменных** (`на руки`) — самая хрупкая часть движка: `на` в другом контексте может оказаться частью другого имени. Решение — жадный поиск самых длинных известных имён и тесты на пересечения. Запасной вариант — подчёркивание вместо пробела.
- **Единицы и функции с одинаковыми именами** (`min`, `h`, `s`): правило «число + единица» нужно покрыть тестами.
- **Миграция IndexedDB:** проверить на базе, созданной старой версией, до мержа.
