# Calqnotes — Спецификация

Интерактивный вычислительный блокнот. Современная переработка [Calque](https://github.com/grimalschi/calque) с новыми технологиями и улучшениями.

## Платформа

- **Веб** — единственная целевая платформа
- **Аудитория** — обычные пользователи

## Общее описание

Система представляет собой интерактивный вычислительный блокнот. Пользователь вводит строки выражений. Каждая строка может содержать математическое выражение или объявление переменной. Результат вычисления отображается рядом со строкой. Все строки образуют вычислительный граф зависимостей. При изменении строки автоматически пересчитываются зависимые строки.
