# UI спецификация

Дизайн — по [макетам](https://claude.ai/artifact/FQ9E2gmpqFpLNG2vSEt6r2), план перехода — в [redesign.md](./redesign.md).

## Раскладка

### Десктоп и планшет (от 768 px)

- **Шапка:** логотип · «Заметки Ctrl K» (открывает палитру) · `/` · редактируемое название · статус сохранения · кнопки: новая заметка, «Точность», шпаргалка, настройки, меню «…».
- **Редактор** по центру, ширина текста до 760 px.
- **Шпаргалка** — панель справа (380 px) без затемнения: можно писать, не закрывая её.
- Сайдбара нет: список заметок открывается палитрой.
- До 1024 px подписи «Точность», статус сохранения и подсказка про название скрываются, чтобы шапка помещалась в одну строку.

### Телефон (до 768 px)

- Два экрана: **список заметок** (поиск, даты, превью, «Новая заметка») и **редактор** на весь экран.
- Шапка редактора: «назад» к списку · название и статус · кнопка точности (`0,00`) · меню «…».
- **Строка символов** над клавиатурой: `+ − × ÷ % ( ) = #`.
- Меню заметки и точность — шторка снизу (Drawer).
- Настройки — отдельный экран со всеми разделами подряд.
- Тач-цели не меньше 44 px; текст редактора на 1 px крупнее, строки на 2 px выше.

## Редактор (CodeMirror 6)

- Один текст на заметку, строки через `\n`. Номера строк по умолчанию скрыты.
- Шрифт Geist 15/28 (настраивается: шрифт, размер 14/15/16/18).
- Подсветка: переменные (в том числе из нескольких слов) — `syntax-variable`, функции, единицы, `of / to / last` — `syntax-function`, операторы — `syntax-operator`, комментарии `#` — приглушённые.
- Строка под мышью и строка с курсором подсвечиваются фоном.
- Длинные строки переносятся (отключается в настройках).

### Результат строки

- **Плашка сразу после выражения**, табличные цифры. Если не помещается — уходит на следующую визуальную строку.
- Формат — по настройкам «Формат чисел» и точности заметки.
- **`≈`** перед числом, если показанное значение округлено. Подсказка при наведении: «Точно: 833,3333333333334 · Клик — скопировать».
- **Клик — копирование**: в буфер попадает показанное значение (обычные пробелы, `-` вместо `−`), плашка на 1,5 с превращается в «✓ Скопировано», внизу тост «Скопировано: …».
- Строка, которая только задаёт число (`цена = 1500`), результата не показывает.
- **Вспышка** плашек, чей результат пересчитался из-за правки другой строки (1 с).

### Ошибки

- Плашка с иконкой и текстом на русском: «Нет переменной «на рукки»», «Нет единицы «kgg»», «Не хватает «)»», «Деление на ноль» и т. д.
- Неизвестное имя подчёркнуто волнистой линией.
- **«Возможно, на руки?»** — кнопка-подсказка с ближайшим известным именем, клик заменяет опечатку.
- Пока строку набирают (пауза меньше ~1 с), ошибка не показывается — вместо неё `…`.

### Подсветка зависимостей

Наведение на имя переменной: строка, где она задана, — `var-def`, строки, где используется, — `var-use`. Отключается в настройках.

### Автодополнение

- Переменные выше курсора со значением и источником («Переменная из строки 3: …»), `last`, функции с описанием.
- Бейджи `x` (переменная) и `ƒ` (функция). Tab или Enter — вставить, Esc — закрыть.
- Отключается в настройках.

### Пустая заметка

- Плейсхолдер «Напишите выражение, например 1250 * 12 - 15%».
- Под ним — кнопки-примеры для вставки и ссылка на шпаргалку; исчезают, когда в заметке появляется текст.
- На пустой строке с курсором — подсказка «Новая строка: число, выражение или заметка после #».

## Точность

- Кнопка в шапке: «Точность Авто» + точка, если у заметки своя точность.
- Поповер: Авто / Целые / 1 знак / 2 знака / 4 знака с примером `2500 / 3 → …`; переключатель «Эта заметка / Все заметки»; ссылка в настройки.
- То же — в меню заметки (подменю) и в шторке на телефоне.

## Заметки

- **Палитра (Ctrl K):** поиск по названию и тексту с подсветкой совпадения («— в тексте»), дата изменения, превью первой строки с расчётом.
- В строке палитры: переименовать на месте (F2), дублировать, удалить (Del при пустом поиске).
- Ничего не нашлось — «Создать заметку «…»».
- **Меню заметки «…»:** переименовать (F2), дублировать, скопировать с результатами, «Скачать .txt» (неактивно, «Скоро»), точность в этой заметке, удалить (Ctrl Del).
- **Удаление** — сразу, с тостом «Заметка «…» удалена · Отменить» (6 с).
- **Название:** поле в шапке; пустое — заголовок берётся из первой строки, иначе «Без названия».

## Сохранение

- **Автосохранение** через 1 с после ввода (отключается в настройках).
- Статус в шапке: «✓ Сохранено» · «Сохраняется…» · «Не сохранено Ctrl S» (без автосохранения) · «Не удалось сохранить · Повторить».
- Ctrl S — сохранить сейчас.
- Предупреждение при закрытии вкладки, пока изменения не записаны.

## Настройки

Диалог с разделами (на телефоне — экран):

| Раздел | Параметры |
|--------|-----------|
| Формат чисел | Предпросмотр · Округление: авто / знаки после запятой / значащие цифры + число знаков · Разделитель разрядов · Дробная часть · Экспоненциальная запись (от 10¹², от 10¹⁵, никогда) · Нули в конце |
| Внешний вид | Тема (как в системе / светлая / тёмная) · Шрифт (Geist / системный / моноширинный) · Размер текста |
| Редактор | Номера строк · Автосохранение · Подсветка переменной · Подсказки при вводе · Перенос строк |
| Данные | Где хранятся заметки · «Скачать все заметки (.txt)» — «Скоро» |

Округление влияет только на отображение: в расчётах и в `last` всегда точное значение.

## Шпаргалка

- Поиск по разделам: основы, проценты, переменные и `last`, единицы, функции, комментарии.
- Результаты примеров считает движок с текущим форматом чисел.
- «Вставить» добавляет пример строкой в конец заметки.
- Клавиши: Ctrl K, Ctrl D (дублировать строку), Ctrl / (комментарий), Ctrl Z, Tab, клик по результату.
- «Открыть заметку-пример» — создаёт её заново.

## Первый запуск

Создаётся заметка-пример «Как пользоваться» и баннер «Это заметка-пример…» с кнопкой «Скрыть подсказку».

## Клавиатура

| Клавиши | Действие |
|---------|----------|
| Ctrl K | Палитра заметок |
| Ctrl S | Сохранить сейчас |
| F2 | Переименовать заметку |
| Ctrl Del | Удалить заметку (вне поля ввода) |
| Ctrl D | Дублировать строку |
| Ctrl / | Комментарий `#` для строк |
| Tab | Принять подсказку |
| Ctrl Z / Ctrl Shift Z | Отменить / повторить (история своя у каждой заметки) |

## Тема и токены

- Цвета — CSS-переменные в `src/index.css` (`:root` и `.dark`): токены shadcn и свои токены редактора (`syntax-*`, `var-def`, `var-use`, `approx`, `flash`, `result-hover` и др.).
- Тема: как в системе / светлая / тёмная, хранится в настройках.
- Радиусы: 6 — плашки, 8 — кнопки, 12 — поповеры, 16 — диалоги, 20 — шторка.
- Иконка приложения — логотип (две линии в скруглённом квадрате) белым на `primary` `#C2410C`: `public/favicon.svg`, PNG и ICO для вкладки, iOS и манифеста. Цвет панели браузера (`theme-color`) — фон приложения: `#FBFAF8` в светлой теме, `#161615` в тёмной.

## Доступность

- Все действия — настоящие `button` / `input` с подписями; иконки — `aria-label`.
- Ошибка и округление обозначаются не только цветом: иконка, текст, `≈`.
- Контраст текста — не ниже 4.5:1 в обеих темах.

## Локализация

- react-i18next, переводы колоцированы со слайсами (`translations.ts` + `injectTranslation` в `index.ts`).
- Ключи плоские, точка — часть имени (`error.incomplete`).
- Сейчас только русский; английский — отдельной задачей.
- Подробнее: [docs/coding-standards.md](../docs/coding-standards.md#локализация-react-i18next)
